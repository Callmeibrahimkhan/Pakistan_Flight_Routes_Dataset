# Pakistan Flight Routes Dataset

A structured dataset of airline flight routes connecting Pakistan with domestic and international destinations.

## Dataset Overview

This dataset contains structured information about airlines, flight routes, departure airports, arrival airports, and flight durations.

It is designed for:

* Data Analysis
* Data Engineering
* ETL Pipeline Projects
* SQL Database Projects
* Flight Route Analysis
* Airline Data Visualization
* AI/LLM Chatbot and RAG Projects

## Dataset Columns

| Column              | Description                 |
| ------------------- | --------------------------- |
| SERIAL NO           | Unique serial number        |
| AIRLINE             | Airline name                |
| AIRLINE IATA CODE   | Airline IATA code           |
| FLIGHT NO           | Flight number               |
| FLIGHT TYPE         | Domestic or international   |
| ROUTE               | Flight route                |
| DEPARTURE COUNTRY   | Departure country           |
| DEPARTURE CITY      | Departure city              |
| DEPARTURE AIRPORT   | Departure airport           |
| DEPARTURE IATA CODE | Departure airport IATA code |
| ARRIVAL COUNTRY     | Arrival country             |
| ARRIVAL CITY        | Arrival city                |
| ARRIVAL AIRPORT     | Arrival airport             |
| ARRIVAL IATA CODE   | Arrival airport IATA code   |
| FLIGHT DURATION     | Approximate flight duration |

## Coverage

The dataset focuses on flight routes involving Pakistan and includes domestic and international routes operated by multiple airlines.

## File

* `pakistan_airline_routes.csv` — Main dataset

## Data Usage

This dataset can be used for educational, analytical, and data engineering projects.

Airline routes and schedules can change over time. Users should verify current route information with the respective airline before using the dataset for travel-related decisions.
